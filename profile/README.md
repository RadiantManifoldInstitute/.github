# Radiant Institute for Manifold Studies

The Radiant Institute for Manifold Studies is an independent research institute publishing work on adaptive systems, information retrieval, and meaning manifold dynamics.

## Public preprints

- [Allostatic Control Systems: Goal Governance in Changing Environments](https://arxiv.org/abs/2607.21771) - goal governance in changing environments; arXiv preprint, not peer reviewed.
- [More Context, Same Budget: Dual-Bounded Relational Recall Beyond Top-K Retrieval](https://arxiv.org/abs/2608.18448) - bounded relational context allocation for supporting-evidence recovery; arXiv preprint, not peer reviewed.

Read the [publication index](https://github.com/RadiantManifoldInstitute/radiant-publications) for institute records, citation links, and release boundaries. The [Radiant Institute website](https://www.theradiantinstitute.org/preprints) is the public home for the preprints.

Founder: [Thomson D. Nguy](https://orcid.org/0009-0004-8458-1638).

Public research records do not imply that code, data, source archives, or replication packages have been released.
